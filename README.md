# Superinformation

This code implements a novel, training-free approach for distinguishing between coding and noncoding regions in DNA sequences using the concept of superinformation-a measure of the "randomness of randomness" in a sequence. The method leverages the statistical differences in base distribution and higher-order randomness between coding (exonic) and noncoding (intronic and intergenic) DNA regions, enabling highly accurate and efficient classification without the need for prior training or labeled data.
